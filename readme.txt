TRAVYN OLD UI + ALL FEATURES

1. Extract ZIP
2. Rename .env.example to .env
3. Add your SMTP email details for email notifications
4. Add your Cloudinary keys for image upload
5. Double click START-WEBSITE.bat
6. Open http://localhost:3000

Admin panel includes:
- Products, category, orders, users
- GST billing
- Cloudinary product/category/review/home image uploads
- Firebase live update using old firebase-config.js
- SEO Setup panel visible only after admin login
- Notifications to registered WhatsApp/email

Note: Email and Cloudinary need real .env keys. If you open index.html directly, backend email/upload will not work. Use START-WEBSITE.bat.
